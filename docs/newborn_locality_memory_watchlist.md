# Newborn locality / memory watchlist

> **Status:** bibliographic watchlist only. Full texts for the items below were not
> obtained in the current audit, so no theorem-level comparison is inferred from
> titles alone.

The historical novelty search around Kim–Newborn input restrictions surfaced a
cluster of earlier/lateral work by Monroe M. Newborn that is potentially relevant
to the **remaining bounded-local extremal CCOC candidate**.

## Items requiring full-text review

### Newborn (1968)

**“Maximal Memory Binary Input-Binary Output Finite-Memory Sequential Machines.”**
*IEEE Transactions on Computers* 17(1):67–71.

This title is especially important for the CCOC memory-sharpness audit because
the current relay realizes a binary controlled system whose open interface
retains the maximum possible dormant-memory distinctions on the declared domain.
No conclusion about equivalence or subsumption should be drawn before the paper
is read.

### Hsieh, Tan & Newborn (1968)

**“Uniform modular realization of sequential machines.”**
ACM National Conference 1968:613–621.

Potential relevance: repeated finite modules / uniform realization of large
sequential machines. The current CCOC witness uses a repeated constant local
state/message grammar, so this is a direct architectural-history target.

### Arnold, Tan & Newborn (1968)

**“Iteratively Realized Sequential Circuits.”**
SWAT 1968:431–448.

Potential relevance: iterative / repeated sequential-circuit realization.

### Arnold & Newborn (1969)

**“Iteratively Realized Sequential Circuits: Further Considerations.”**
SWAT 1969:194–212.

Potential relevance: follow-up architecture theory for iterative sequential
circuits.

### Newborn & Arnold (1972)

**“Universal Modules for Bounded Signal Fan-Out Synchronous Sequential
Circuits.”**
*IEEE Transactions on Computers* 21(1):63–79.

Potential relevance: bounded fan-out / modular synchronous realization, directly
adjacent in vocabulary to the current bounded-degree constant-local relay.

## What the watchlist changes

Until these papers are checked in full, CCOC should not make a priority statement
about being the first bounded-local / constant-local-grammar realization of a
large sequential-memory family.

The current claim remains only:

> CCOC supplies an explicit degree-three, pairwise, constant-local, four-symbol
> construction that realizes the maximal one-action open-interface innovation
> and saturates its declared local query-latency bound; no direct match has yet
> been established in the literature reviewed so far.
