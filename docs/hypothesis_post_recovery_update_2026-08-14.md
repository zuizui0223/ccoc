## HYP-I04 — endogenous feedback-network portability

The hypothesis was open at the recovery pin. It is now substantially resolved in four deterministic subtheorems:

1. **PR #204 — scalable feedback-gate rank.** Independently addressable endogenous feedback modes require exactly `r` hidden-feedback bits; removing either causal arrow of the feedback cycle collapses the burden to zero.
2. **PR #205 — bounded-type feedback portability.** One copy-anonymous interaction type has a canonical five-state quotient independent of physical replication; fixed `q` types give one `5^q`-state changing-domain macro.
3. **PR #207 — evolving master feedback types.** Context-dependent type maps `tau_c(m)` close exactly through the master signature `tau*(m)`. Bounded instantaneous type count alone is insufficient: a rotating family has two types per context but `2^r` master classes and `r` exact bits.
4. **PR #208 — future-context causal forgetting.** Under autonomous context evolution, the master signature may be restricted to contexts still reachable from the present. Future feedback rank is non-increasing, and an irreversible chain realizes exact memory `r,r-1,...,0` bits.

### Remaining open boundary

The current unresolved deterministic case is narrower:

> context reachability itself depends on ecological macrostate and/or hidden interaction mode, so feedback changes which future contexts exist.

PR #208 deliberately fails closed on this case. A new theorem would need a state-dependent future-context closure or a matching lower-bound obstruction. Generic canonical quotient computation alone is not the intended structural result.
