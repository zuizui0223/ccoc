# RACH package boundary: publication core versus legacy shelf

## Publication question

The active source archive supports one manuscript question:

> When does exact finite compression in each fixed closed composition fail to
> extend to one small exact interface for a declared open composition grammar?

The active theorem spine is:

1. **Exact grammar-aware factorization.** A finite update-consistent summary
   yields an exact interface for a declared controlled system and legal grammar.
2. **Extension--compression obstruction.** A jointly realizable product with
   uniform legal coordinate decoders forces an open-interface lower bound and,
   with closed factorizations, a noncommutation gap.
3. **Conservative portability boundary.** A common finite schema survives
   declared legal-action growth only when old meanings persist and new actions
   are uniform inside macro fibers.

The binary relay tree is a sharpness realization of item 2. It is not a separate
headline theory.

## Active public facade

```python

```

This facade exposes only `CORE-1`--`CORE-5` needed by the manuscript. It does
not expose finite closure classification, non-nested transport, candidate
uncertainty, delayed evidence, or experimental-design branches.


They are not public entrances for new work and are excluded from the default

## Migration status

| Group | Current status | Physical source-path policy |

| `CORE-0`, `EXT-1`--`EXT-4`, `ID-1`--`ID-3`, `LEGACY-1` | archived in `legacy/manifest.md` | original paths retained temporarily for import compatibility |

The post-submission move will place archived implementations under
`causal_model.legacy`, archived tests under `legacy/tests`, and archived replays
under `legacy/scripts`. Until then, forwarding/compatibility behavior is
preferred over a simultaneous import-breaking rewrite.

## Source-of-truth rule

- `extension_compression_noncommutation.py` is the canonical source for the
  addressable-product theorem and noncommutation inequality.
- `operational_addressability.py` supplies finite operational witnesses; it does
  not infer a grammar, decoder, or ecological mechanism from data.
- `extension_compression.py` and `relay_tree_compilation.py` are sharpness
  witnesses only.
- `conservative_macro_schema.py` and its local fiber-split certificate supply the
  positive and local-negative boundary used by the paper.

## Non-goals during manuscript freeze

- no new local grammar theorem;
- no replacement, stochastic, continuous, approximate, or candidate-uncertain
  extension;
- no panel, coverage, robustness, or field-protocol theorem;
- no empirical data ingestion or ecological case-study inference.
