# Confidence-set lifting theorem

## Aim

This document gives RACH a genuinely data-type-agnostic soundness layer.
It does **not** require that observations are binary, ecological, independent,
identically distributed, continuous, discrete, low-dimensional, or generated by
one of RACH's built-in simulators.

Instead, an external statistical procedure converts arbitrary random data into
sets of retained candidate explanations and supplies a valid simultaneous
coverage statement. RACH then converts that coverage statement into a
simultaneous bound on false decisive causal conclusions.

The claim is deliberately conservative:

> RACH is universally **sound conditional on coverage**, not universally
> decisive and not a machine for discovering true mechanisms from unrestricted
> data.

## Setup

Let:

- \(\Theta\) be a finite predeclared candidate universe;
- \(M(\theta)\subseteq\mathcal M\) be the motifs active in candidate
  \(\theta\);
- \(Z\) be an arbitrary random element on any measurable data space, including
  any randomization used by the analysis procedure;
- \(\mathcal R\) be the required robustness cells; and
- \(C_r(Z)\subseteq\Theta\) be an externally produced retained-candidate set
  for cell \(r\).

There is no requirement here that \(Z\) is an i.i.d. sample, that candidates
are likelihood models, or that cells are independent. All of that belongs to
the external method that establishes coverage.

RACH classifies a motif \(m\) from the required retained sets as:

```text
INVARIANT  if every candidate in every required C_r(Z) has m
EXCLUDED   if no candidate in any required C_r(Z) has m
UNRESOLVED otherwise
UNSUPPORTED if a required C_r(Z) is empty
```

This is equivalent to the existing robust-admissibility classifier after each
retained candidate set is represented as accepted `ProgramRun`s.

## Theorem: confidence-set lifting

Assume that \(\theta^\star\in\Theta\) is the true candidate and that an
external procedure supplies the simultaneous coverage guarantee

\[
\Pr\left[
  \theta^\star \in \bigcap_{r\in\mathcal R}C_r(Z)
\right] \ge 1-\alpha.
\]

Then RACH satisfies the finite-sample family-wise guarantee

\[
\Pr\left[
\exists m\in\mathcal M:
\begin{array}{l}
  m\notin M(\theta^\star)\;\text{and RACH reports INVARIANT},\\
  \text{or}\\
  m\in M(\theta^\star)\;\text{and RACH reports EXCLUDED}
\end{array}
\right] \le \alpha.
\]

In words: the chance that RACH makes **any** false decisive claim across all
motifs is no larger than the joint probability that the external confidence
procedure omitted the true candidate from at least one required cell.

### Proof

Condition on the event

\[
E = \{\theta^\star\in C_r(Z)\ \text{for every required}\ r\}.
\]

On \(E\), every required retained set contains \(\theta^\star\). If RACH
reports `INVARIANT` for a motif absent from \(\theta^\star\), then the
required set containing \(\theta^\star\) contains a candidate without that
motif, contradicting `INVARIANT`. If RACH reports `EXCLUDED` for a motif active
in \(\theta^\star\), the same retained candidate contradicts `EXCLUDED`.
Therefore a false decisive conclusion cannot occur on \(E\):

\[
\{\text{any false decisive RACH conclusion}\}\subseteq E^c.
\]

Taking probabilities proves the result.

The proof is pointwise in the realized data. Consequently it introduces no
assumption on the distribution of \(Z\); all distributional assumptions are
contained in the external proof of the coverage statement.

## Uniform version: arbitrary random-data families

Let \(\mathcal P\) be any class of possible data-generating distributions. If
an external set-valued procedure has **uniform** simultaneous coverage

\[
\inf_{P\in\mathcal P}
\Pr_P\left[\theta(P)\in\bigcap_{r\in\mathcal R}C_r(Z)\right]
\ge 1-\alpha,
\]

then the RACH family-wise false-decisive probability is also at most \(\alpha\)
uniformly over \(\mathcal P\).

This is the precise meaning in which RACH can apply to arbitrary random data:
RACH is a distribution-agnostic *lifting layer*. It does not care whether the
underlying valid confidence sets came from exact combinatorics, a martingale
bound, randomization inference, a permutation argument, a conformal guarantee
under exchangeability, or another method. It only requires that the claimed
coverage actually holds over the declared data-generating class.

## Why universal decisiveness is impossible

Suppose two candidates \(\theta_0\) and \(\theta_1\) have identical data
distributions, but a motif \(m\) is absent from \(\theta_0\) and active in
\(\theta_1\). Under a common coverage error bound \(\alpha\):

- `INVARIANT` has probability at most \(\alpha\) under \(\theta_0\), because
  it would be false; and
- `EXCLUDED` has probability at most \(\alpha\) under \(\theta_1\), because
  it would be false.

The two candidates generate the same distribution, so the probabilities of the
observable RACH statuses are the same under both. Therefore

\[
\Pr(\text{INVARIANT or EXCLUDED})\le 2\alpha,
\]

and

\[
\Pr(\text{UNRESOLVED or UNSUPPORTED})\ge 1-2\alpha.
\]

This is not a defect. It is the necessary price of a theorem that does not make
false certainty from observationally indistinguishable random data.

## What RACH must and must not claim

RACH may claim, conditional on a valid certificate:

```text
At family-wise error rate at most alpha,
no reported invariant or excluded motif is false within the declared universe.
```

RACH must not claim:

```text
The certificate is valid merely because RACH received it.
The candidate universe contains nature.
Any arbitrary data set will yield a decisive result.
A sampled candidate grammar is exhaustive.
```

Statistical coverage and candidate-universe coverage are different objects:

- **statistical coverage** asks whether the true candidate is retained with high
  probability under random data;
- **candidate coverage** asks whether the true mechanism was included among the
  candidates at all.

The theorem controls the first conditional on the second. It cannot repair an
omitted mechanism.

## Code mapping

`causal_model.confidence_lifting` implements the deterministic part of the
proof and the bookkeeping for an external coverage statement.

| Mathematical object | API |
|---|---|
| \(\Theta, M(\theta)\) | `CandidateMotifUniverse` |
| \(C_r(Z)\) | `CandidateAcceptanceSet` inside `ConfidenceSetCell` |
| External coverage statement | `JointCoverageCertificate` |
| Pointwise inclusion of false decisiveness in miscoverage | `deterministic_lifting_witness` |
| Lifted family-wise upper bound | `soundness_guarantee_from_joint_coverage` |
| Indistinguishable-pair abstention lower bound | `indistinguishability_abstention_lower_bound` |

The API never accepts raw field data. A separate adapter may be written later
for a particular statistical method, but it must state and test that method's
own assumptions rather than weakening this theorem.
