## External use contract

The library's current external-user guidance permits on-site viewing and copying
of physical books/journals. For a person affiliated with a non-partner university,
the stated route requires an introduction letter from the home university library.
Other external-user categories follow the identification rules on the library's
external-user page.

Current on-site copy-machine guidance states:

- **10 yen per copied sheet**;
- library-held material only;
- one research copy per user within Copyright Act Article 31;
- an individual article in an old periodical issue may be copied in full after the
  relevant publication interval has elapsed.

This is an on-site reading/copy route; no direct postal external-user service is
claimed here.

## Efficient reading order

1. **C-24(8)** first: Williams + Le Van–van Houtte resolve resynthesis and timing in
   one issue.
2. If Le Van–van Houtte contains a disputed/corrected step, read **C-27(2)** next.
3. Read **C-27(10)** for later implementation/resource interpretation.
4. Use **C-31(2)** last as the comparative retrospective source.

This order prevents the 1978/1982 papers from being used as second-hand substitutes
for the 1975 primary constructions.

## Evidence rule

The fact that all sources are physically obtainable does **not** promote any
compiler clause. H1–H4 change only after the relevant primary text is read.
